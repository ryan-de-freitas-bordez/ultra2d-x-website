# Ultra2D-X Website

A responsive static landing page for Ultra2D-X, a 2D framework project built on Cocos2d-x 4.0.

## Files
- `index.html` — page structure and Ultra2D-X API example
- `styles.css` — dark blue/cyan theme, angled navigation tabs, responsive layout, and font styles
- `script.js` — mobile navigation and copy-code button

## Fonts
Inter is used for page text and Fira Code for code samples. They are loaded from Google Fonts in `index.html`, so an internet connection is required for the web fonts. CSS includes fallback fonts.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## API example note
The quick-start sample follows the API sketch supplied for Ultra2D-X. It is a display example and has not been verified as compilable; confirm function signatures and return types against the implementation as it develops.
